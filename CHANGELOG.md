# Changelog

## Unreleased — developer preview

- Self-hostable API, web checkout, worker and PostgreSQL ledger for one merchant's versioned digital products.
- Human wallet and upstream x402 agent purchasing, independently verified settlement, authenticated private delivery and same-purchase recovery.
- Merchant settings, separate pauses, readiness, receipts, delivery retry and manually approved refund operations.
- Additive merchant-site and receipt-adapter examples; ordinary checkout remains independent.
- Automated native local walkthrough with generated wallets and synthetic tokens, plus payment, authorization, concurrency, refund and recovery regressions.
- Fail-closed PostgreSQL connection handling and disposable local-wallet signing guards.

This is not a production release. Mainnet is disabled; container, real-wallet and production security qualification remain incomplete. Public licensing is pending owner approval.
